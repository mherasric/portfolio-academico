## Documentos Disponibles

### 1. Memoria de Prácticas: Procesamiento de Señales de Radar
* **Temática:** Análisis y procesamiento digital de señales (DSP) aplicadas a radares FMCW.
* **Resumen:** Este documento detalla mi trabajo desarrollando algoritmos para aislar el ruido, calcular distancias con precisión sub-bin y detectar vibraciones milimétricas. Todo ello programado en Python (FFT, CFAR, tracking predictivo).
* **Código asociado:** Puedes ver la aplicación práctica de esta memoria en mis repositorios técnicos (añade aquí el enlace a tus otros repositorios).

### 2. Trabajo de Fin de Grado (TFG)
* **Título:** La desigualdad de Prékopa-Leindler como contrapartida analítica de Brunn-Minkowski: Fundamentos, casos de
igualdad y generalizaciones.
* **Temática:** Geometría convexa y análisis.
* **Resumen:** Este trabajo conecta la geometría de las figuras con el cálculo de sus integrales. Resolví paso a paso cómo el comportamiento del volumen al sumar conjuntos se traduce en una regla matemática exacta para operar con funciones. Como logro principal, demostramos que esta unión teórica preserva propiedades estructurales como la log-concavidad y ampliamos toda la teoría clásica a promedios mucho más generales.
